## What AegisTools Does

Built for Java-based Minecraft servers using Paper, AegisTools handles several repetitive actions that normally require manual inventory management. It can identify an appropriate tool for the block being targeted, replenish usable items from the player's inventory, and arrange tools across the hotbar.

The plugin also provides an in-game block blacklist GUI. Players can use this interface to decide which blocks should be ignored by the tool-selection process without editing an external configuration. Its core functionality is centered on block-breaking assistance and inventory-related helpers.
